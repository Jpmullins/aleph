## Problem

The 2026-07-02 audit named a set of confirmed bugs and dormant subsystems. WP-1..WP-4 removed
the AIQ surface and rearchitected the workspace; this package finalizes and executes the
kill/fix list against what remains, each fix with a named regression test, and adds the

## Design — the finalized kill/fix list

### Bugs (each gets a named regression test)

1. **Embedding-dimension guard on initial ingest.** `chunk_embed_job` embeds (bills) before any
   dimension check. Add a guard that resolves the project's embedding binding's expected
   dimension and **rejects before calling `embed_texts`** when the model's dim ≠ the pgvector
   column width (mark the source `failed` with a clear reason, no embedding spend). In the
   re-embed path (`retrieval.reembed_for_project`), a dim mismatch must be **marked and skipped
   without incurring model cost** (check dim before embedding, not after). Tests:
   initial-ingest mismatch → rejected pre-embed, zero `ModelCall`; re-embed mismatch → marked,
   zero `ModelCall`.
2. **`verify_project_chain` walks `prev_event_id`.** It currently orders by `timestamp, id` and
   iterates that. Rewrite to walk the hash chain via `prev_event_id` from the chain head.
   Tests: a chain whose rows are timestamp-reordered but `prev_event_id`-valid still verifies;
   a tampered `chain_hash`/broken link fails.
3. **Honest artifact kinds.** `report_docx`/`deck_pdf` fall through to the markdown-bundle
   branch (mislabeled `.zip`). Since no docx/deck exporter exists, **400 those kinds**: tighten
   the route pattern (`routes/artifacts.py`) and the `artifact_service` allowlist to exactly
   what the builder produces (`report_pdf`, `report_markdown_bundle`, `source_pack`). Test: a
   `report_docx`/`deck_pdf` build request → 400; each accepted kind produces its real format.
4. **Agent self-calls use short-lived agent tokens.** Replace every hardcoded
   `Authorization: Bearer local-dev` in production self-call sites (`copilot_agent.py` ~11
   sites + its `local-dev` principal builder, `a2ui_handlers._self_post`, `subagents/
   {wiki_builder,reviewer,researcher}.py`) with `mint_agent_token(...)` scoped to the acting
   project/agent_run (the pattern already used by routes/workers). Test: a self-call helper
   produces a token that `verify_agent_token` accepts and that is NOT the sentinel; assert no
   `Bearer local-dev` remains in `apps/api/src`/`packages` production code (grep test). The
   frontend local-mode sentinel (`apps/web/src/lib/auth.ts`) stays (documented local-auth).
5. **Library rename stragglers.** Fix the user-facing "Open in Artifacts" label
   (`ArtifactCard.tsx`) → "Open in Library". The "Artifacts" *sub-heading* inside Library
   (Sources + Artifacts sections) is correct and stays. Internal component names
   (`ArtifactsSurface`) are out of scope.
6. **Python pinned to 3.13.** Add a root `.python-version` (`3.13`) and constrain
   `requires-python` to `>=3.13,<3.14` in the root + all workspace `pyproject.toml`; re-resolve
   the venv on 3.13. Verify `python -V` is 3.13.x and `uv sync` succeeds.
7. **`.env.example` ↔ settings reconciled by a unit test.** Author a unit test that parses
   `deploy/compose/.env.example` and both `Settings`/`WorkerSettings`, and asserts: every
   **required** settings field (no default) has a corresponding key in `.env.example` or the
   compose environment; and every `ALEPH_*` key in `.env.example` maps to a real settings
   field (allowing a documented ignore-list for container-only keys: `POSTGRES_*`, `LANGFUSE_*`
   infra, `MINIO_ROOT_*`, `VITE_*`, connector API keys consumed in the connectors layer). Fix
   the concrete gap it surfaces first: the worker's **required** `aleph_api_internal_url` has no
   `.env.example` key — add it (or give it the compose default).

### Dead/dormant subsystems

8. **Writer-less assistant persistence.** `AssistantMessage`/`append_message` has zero
   production writers (chat runs through CopilotKit, which persists nothing here). Per the
   datasets rule (keep ORM tables, delete broken/unproduced *paths*): **delete `append_message`
   and the never-populated message read-route**, keeping the `AssistantSession`/`Thread`/
   `Message` tables and the session/fork CRUD the web uses. Written justification recorded.
9. **Dead routes.** Run the new route-reachability sweep (below); for each mounted route with
   zero web *and* zero agent/self-call callers, **delete the route** (keeping ORM tables where
   the datasets rule applies). Candidates to adjudicate: `handedits`, `aliases`,
   `merge_proposals`, `chunks`, `datasets`, `evals`, `connector_credentials`, `feedback`,
   `hypotheses`. Any that a card-action / agent path reaches through a non-obvious route stays
   (the sweep must account for agent-token self-calls + `/cards/actions`, not just `apps/web`
   fetches) — e.g. `connector_credentials` is reached by `scripts/connect-consensus.py`
   (WP-2), so it **stays**. Each deletion is justified in the impl-log.
10. **Dead fields.** The `AssistantMessage` write-only columns die with #8. No other confirmed
    dead columns; the route-reachability + roster sweeps cover the structural cases.

### Sweeps (committed, CI-wired)

11. **Route-reachability sweep** `scripts/check-route-reachability.sh`: enumerate
    `app.include_router(...)` mounts + their route paths, and assert each path prefix is reached
    by either `apps/web/src` (fetch/EventSource/apiUrl) or an agent/self-call site
    (`mint_agent_token` callers + `/cards/actions` handlers) — with an explicit, commented
    allowlist for intentionally-external routes (e.g. `connect-consensus.py`'s
    `connector-credentials`, the smoketest route). Fails on a mounted route reached by nobody.
    The catalog producer/renderer sweep (`check-catalog-roster.sh`) already exists from WP-4.

    Zero errors throughout.
