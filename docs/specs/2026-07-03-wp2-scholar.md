# WP-2 — `aleph-scholar`: verified scholarship + Consensus

**Date:** 2026-07-03 · **Package:** WP-2 of `GOAL.md` · **Proves:** F2 (scholar half)
**Status:** implementing

## Problem

Research output currently cites whatever the LLM emits. Nothing verifies that a cited DOI
exists, nothing detects retracted papers, there is no citation-graph expansion, and the one
high-quality evidence source the user subscribes to (Consensus) is unreachable from the
research loop. Ingested papers don't record their scholarly identity (`doi`, `openalex_id`),
so downstream trust features (WP-6 retraction blast-radius) have nothing to key on.

## Design

### 1. Package: `packages/aleph-scholar`

Pure-HTTP service package — **zero LLM calls** (no `LiteLLMClient`, no `ChatOpenAI`, no
provider SDK; enforced by grep + review). Deps: `httpx==0.28.1`, `tenacity`, `mcp>=1.28,<2`
(first MCP *client* in the codebase). *(Amended 2026-07-03 at implementation:)* the package
carries **no workspace deps** — credentials and persistence are injected as async callbacks
(the API layer binds them to `ConnectorCredentialService`), and redis is duck-typed via a
`RedisLike` Protocol; the originally-listed `aleph-core`/`aleph-connectors`/`aleph-db`/
`aleph-security`/`aleph-observability` deps proved unnecessary. Registered in root
`pyproject.toml` (workspace members, uv sources, ruff src, pyright include). Shape copied
from `aleph-aiq` (`AIQClient`). Unexpected non-404 4xx from either upstream folds into the
transient error type (→ tri-state `ok=None`), never an unhandled exception.

Public API (`aleph_scholar.service.ScholarService`, plus pure functions):

```python
@dataclass(frozen=True)
class DoiVerdict:
    doi: str                      # normalized lowercase, no https://doi.org/ prefix
    ok: bool | None               # True=resolves, False=authoritative 404 on BOTH
                                  # Crossref and OpenAlex, None=network-unverifiable
    retracted: bool | None        # True=retraction detected, False=verified-not,
                                  # None=unverifiable (ok is False or None)
    title: str | None
    year: int | None
    openalex_id: str | None
    checked_via: str              # "crossref+openalex" | "crossref" | "openalex"

async verify_dois(dois) -> list[DoiVerdict]
async crossref_lookup(query, *, rows=10) -> list[WorkRef]        # bibliographic search
async search_openalex(query, *, per_page=10) -> list[WorkRef]
async expand_citations(ref, *, direction="both", limit=25) -> CitationExpansion
    # ref = DOI or OpenAlex id. backward = referenced_works (what it cites),
    # forward = /works?filter=cites:{id} (what cites it).
async search_consensus(project_id, query, *, filters=None) -> ConsensusResult
def extract_dois(text) -> list[str]                              # regex, deduped, normalized
def style_pass(markdown) -> str                                  # deterministic, LLM-free
```

- **Retraction detection**: OpenAlex `is_retracted` is primary (Retraction-Watch-backed);
  Crossref `update-to`/`updated-by` relations of type `retraction` corroborate. Known-true
  case used in tests: `10.1016/s0140-6736(97)11096-0`.
- **Tri-state discipline**: a DOI is `ok=False` only when both upstreams answer an
  authoritative 404. Timeouts, 429s, 5xx → `ok=None`. Consumers (reviewer) MUST treat
  `None` as "do not flag".
- **`style_pass`** (LLM-free): renumbers citation markers to first-appearance order
  (`[3][1][3]` → `[1][2][1]`), rebuilds the `## References` list to match (dropping
  orphaned entries, preserving unreferenced-entry text under a `Further reading` stanza),
  normalizes each entry to `Authors (Year). Title. Venue. https://doi.org/<doi>` when a
  structured `WorkRef` is attached, and strips duplicate whitespace. Pure function,
  property-tested (idempotent: `style_pass(style_pass(x)) == style_pass(x)`).

### 2. Politeness / throttle

One shared `ScholarHttp` wrapper: `User-Agent: aleph-scholar/0.1 (mailto:$ALEPH_SCHOLAR_MAILTO)`
(settings key, default `dev@aleph.local`), `mailto=` param on OpenAlex (polite pool);
per-host token-bucket at 1 req/s (burst 5); tenacity retry mirroring
`aleph_models.retry.gateway_retry` (3 attempts, exp backoff 1–4s, retry on transport
errors/429/5xx, honor `Retry-After`). Batch endpoints preferred (OpenAlex
`filter=doi:a|b|c` resolves up to 50 DOIs per request; `verify_dois` batches).

### 3. Consensus over MCP + OAuth in `ConnectorCredential`

- **Transport**: MCP streamable-HTTP client (`mcp` SDK) against `https://mcp.consensus.app/mcp`,
  calling its `search` tool. Session per call-burst; no long-lived connection.
- **Credential**: new connector kind `consensus` (migration inserts the `connectors` row,
  `requires_auth=true`, `output_kind=document`; also inserts `crossref`, `requires_auth=false`,
  for provenance naming). The encrypted `cipher_blob` plaintext is JSON:
  `{client_id, token_endpoint, refresh_token, access_token, access_token_expires_at, status}`.
  Stored/rotated exclusively through `ConnectorCredentialService` (ledger
  `connector_credential.create|update`, plaintext never in payloads — existing invariants).
- **Bootstrap**: `scripts/connect-consensus.py` (argparse, self-calls the API — never the DB):
  RFC 9728 protected-resource discovery → RFC 8414 AS metadata → RFC 7591 dynamic client
  registration → PKCE auth-code flow with a localhost loopback redirect (prints the URL and
  opens the browser; **requires the user interactively**) → token exchange → `PUT
  /v1/projects/{pid}/connector-credentials/consensus` (owner-only route, existing).
- **Rotation on refresh**: when the access token is expired/absent, scholar refreshes at the
  token endpoint; if the AS returns a new `refresh_token`, the full blob is re-upserted via
  the credential service (`rotated_at` bumped, ledger event). Concurrency: refresh is
  serialized per project with a redis lock (`scholar:consensus:refresh:{pid}`) so parallel
  tool calls don't race a one-time-use refresh token.
- **Reconnect-required state**: an authoritative refresh rejection sets
  `status="reconnect_required"` inside the blob via the credential service and raises
  `ConsensusReconnectRequired` (the tool surfaces "run scripts/connect-consensus.py").
  *(Amended 2026-07-03 during live verification:)* authoritative = **any HTTP 400/401 from
  the token endpoint** — RFC 6749 puts `error: invalid_grant|invalid_client` in the body,
  but the live Consensus AS is non-conformant and answers `{"detail": "Invalid or expired
  refresh token"}`; a 400/401 on a refresh grant means the grant is dead either way. The
  credentials GET route gains a derived `status` field (server-side decrypt, owner-only;
  plaintext still never returned). Network failures / 5xx during refresh are NOT
  reconnect-required — they raise transient errors.
- **Quota-aware**: Consensus plans meter searches/month. Redis counter
  `scholar:consensus:{project_id}:{YYYY-MM}` incremented per search; cap from settings
  `aleph_consensus_monthly_search_cap` (default 200, under the Pro plan's 250). At cap the
  tool returns a structured "quota exhausted — use search_openalex for discovery" message
  without calling Consensus. Tool guidance (docstring + researcher prompt): Consensus is for
  **screening/evidence questions**, OpenAlex for bulk discovery.

### 4. API routes + subagent tool wiring

New router `apps/api/src/aleph_api/routes/scholar.py` (VIEWER for read ops, EDITOR for
ingest), thin over `ScholarService`:

```
POST /v1/projects/{pid}/scholar/verify-dois        {dois: [...]} → {verdicts: [...]}
POST /v1/projects/{pid}/scholar/search             {provider: openalex|crossref, query} → {works}
POST /v1/projects/{pid}/scholar/expand-citations   {ref, direction, limit} → {backward, forward}
POST /v1/projects/{pid}/scholar/consensus-search   {query, filters} → {hits | quota | reconnect}
```

`consensus-search` enforces the project's `ConnectorBinding` for `consensus` (disabled →
403 `connector_disabled`) — per-project scoping by *binding*, mirroring `aiq_internal`.

The **researcher subagent** (`apps/api/src/aleph_api/subagents/researcher.py`) gains tools
(established pattern: `@tool` async fns that self-call the typed routes): `verify_dois`,
`search_openalex`, `search_consensus`, `expand_citations`, and `ingest_paper(url, doi,
openalex_id, connector_kind, retracted)` → `POST .../sources/ingest-url` with the new
optional fields (below). System-prompt guidance: verify every DOI you cite; ingest what you
rely on; Consensus for screening only.

### 5. Ingest metadata passthrough

`IngestUrlIn` gains optional `connector_kind: str | None` and
`source_metadata: dict | None`. `register_uploaded_source` gains matching optional
parameters (default preserves today's `"upload"` / `{}`). Scholar-ingested papers carry
`connector_kind` = real origin (`openalex` | `crossref` | `consensus` | `arxiv`) and
`source_metadata_jsonb` ⊇ `{doi, openalex_id, doi_verdict: {ok, retracted, checked_via,
checked_at}}`. `connector_kind` is validated against the seeded `connectors` table (unknown
kind → 422) so provenance names stay real. No schema change (columns exist).

### 6. Reviewer citation pass

New deterministic node `doi_verification` in the **MechanicalReviewer** graph (between
`citation_match` and `broken_links`): `extract_dois` over the revision body + the revision's
source registry rows' `source_metadata_jsonb.doi`; `verify_dois` (batched, ≤50/run); emits
findings via `add_finding`:

- `fabricated_doi` (severity `high`) — verdict `ok=False`; evidence_refs carries the DOI +
  both upstream 404s.
- `retracted_source` (severity `critical`) — verdict `retracted=True`; targets the page and
  the source row. (WP-6 wires this same finding kind into blast-radius UI.)
- verdict `ok=None` → **no finding** (network-unverifiable is never flagged) — unit-tested.

Verdicts for DOIs belonging to ingested sources are cached back into that source's
`source_metadata_jsonb.doi_verdict` (same transaction as the review findings, ledger
`source.update`); page-only DOIs use an in-run cache.

### 7. Settings / env

API + workers settings add: `aleph_scholar_mailto` (default `dev@aleph.local`),
`aleph_consensus_monthly_search_cap` (default 200). `.env.example` documents both. No new
compose services, no secrets in env (the OAuth credential lives in the DB).

### 8. Security posture

- OAuth tokens encrypted at rest with the existing per-project sealed-box cipher; decrypted
  only inside `ScholarService` server-side; never logged, never in ledger payloads, never
  returned by any route. Loopback redirect binds `127.0.0.1` with a random port + `state`.
- Scholar egress: `api.crossref.org`, `api.openalex.org`, `mcp.consensus.app` + its
  discovered AS. No agent-controlled URLs (ingest URLs go through the existing ingest route
  and its normalizer, unchanged).
- No LLM calls in the package; no direct DB writes outside `ConnectorCredentialService`,
  `add_finding`, and the source-metadata verdict cache (all ledgered mutations).
- Consensus tool refuses when the project binding is disabled (403 at the route — the same
  enforcement the agent path uses).

### 9. What it deletes

Nothing. (First net-new capability package of the goal; the AIQ deletion is WP-3.)
